## 我们如何共同完成研究

1. **从课堂问题收窄任务。** 由宽泛的“证据不足怎样回答”收窄到固定四个UTC小时的水温统计量，明确对象、时间、变量、单位与运算合同。
2. **作者提出核心主张。** 本站缺失时仍应提供有依据的帮助；站间信息按可靠程度使用；高频计算路径可以复用；推论单独标明，在后续观测到达时回看。
3. **把主张拆成可检验机制。** 在文献与AI协作下，形成逐目标精确证书、本站优先的增量选路、精度门控与时间覆盖补证、保持合同/版本/等级的复用与追加核验。思路和文献依据见报告2.5—2.6、3.7—3.8及个人思路来源。
4. **用负结果修正方案。** 初始跨站路线弱于本站持续性，因而改为“先强本站、再判断增量”；增强模型并非各年各指标都最好，因此保留B/B+等有效对照；精度停止降低补证数量，但没有被写成无代价提升。
5. **形成验证闭环并完善表达。** 用官方源行、输入/评分分离、年份迁移、同点区间、同预算补证、配对区间、缓存消融及2020组合验证逐项核查；再按作者多轮审核整理原创探索、图表、正文结构与提交材料。聊天原文是过程证据，README仅作导航和概括。

## 如何复现

建议在Windows、Python 3.12环境中按requirements.txt安装依赖；既有环境版本记录见environment.json。绘图使用Windows微软雅黑。统一入口会先校验映射清单中的文件哈希，再在临时工作区执行，不覆盖提交目录内的冻结数据和模型。

在仓库根目录执行：

```powershell
python -m pip install -r .\03_实验复现\requirements.txt
.\03_实验复现\运行.ps1 -Python "你的python.exe完整路径"
```

可选完整训练和绘图：

```powershell
.\03_实验复现\运行.ps1 -Python "你的python.exe完整路径" -FullRefit -Figures
```

也可直接运行 `python .\03_实验复现\运行.py --full-refit --figures`。已安装相应依赖时直接执行；入口不需要重新联网下载数据。默认模式重算保存的E1/E4事件、E2/E3统计及冻结E5，并执行实际补证读取。`-FullRefit`重新拟合、开发选择与校准，比较90,180行冻结输出；`-Figures`重建最终15幅图，并比对数据图CSV。日志和核验写入`07_核验/本次复现/`；重新绘图只放在运行临时目录，提交图源仍以`06_可视化/`为准。

ChatGPT/Codex用于协作研究、实现与写作；项目未将当前聊天冒充独立批量语言模型测试。缓存计时属于局部执行实验，组合回放使用预计算基础点预测，不能解释为完整线上服务的时延基准。
